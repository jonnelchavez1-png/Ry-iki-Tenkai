Project overview

AnyJuanPDF is a desktop app that puts the PDF jobs people do every day in one place. It grew out of an earlier plan for a simple PDF merger and now covers much more: organizing pages, merging, splitting, compressing, converting to and from other formats, locking and unlocking, watermarks, page numbers and document details.

It opens on a Home screen that asks “What would you like to do?” and shows each task as a card. Most tools show a live preview of the result, such as the exact page order of a merge, how each page of an Images to PDF file will look, or a before-and-after of a compressed page, so you can check the result before saving.

It is built to be careful with your files. Your original is never changed: every result is saved as a new file, and an existing file is never replaced unless you choose that in the save window. It works offline, nothing is uploaded, and there is no tracking.

What it can do

  • Organize pages: rotate, reorder, delete, duplicate and extract pages with a live preview.
  • Merge: combine several PDFs into one, in the order you choose.
  • Split: split by page ranges, every page, or every N pages.
  • Compress: Basic (lossless), Balanced or Strong, or set the picture quality yourself, and see the real size afterwards.
  • Convert: images to PDF, PDF to images (PNG or JPEG), documents to PDF (CSV, text, HTML, Word and Excel), PDF to Word, and PDF to CSV.
  • Security: password-protect a PDF with AES-256, or remove the password from a PDF you own.
  • Edit: add a text watermark such as CONFIDENTIAL, add page numbers, and view or edit the title, author and keywords.
  • History and settings: a log of what was processed (file names only), a light or dark theme, a default save folder and a default compression level.

How it works

  1. Open the app and pick a task from the Home screen.
  2. Add your files with the Add button, or drop them anywhere on the window.
  3. Set the order and options, and check the live preview.
  4. Save. A new file is created and your original stays untouched.
  5. Find it again later in History.
