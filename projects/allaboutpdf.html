AllAboutPDF

A simple tool for combining several PDFs into one document. The plan is to grow it into a Universal Document Merger, so that any kind of file can be merged.

Status
Planned
Type
PDF merger
Goal
Grow into a Universal Document Merger

What it does

  • Drag and drop your files.
  • Select, remove, and move files up or down to set the order.
  • Combine them into one document.

Why I’m building it

Combining PDFs is an everyday task worth making simpler. When I run into a repetitive or messy process, I like to try fixing it with a small tool.

Where it stands

Planned

This tool is in the planning stage. More details and a preview will be added once it is ready to show.
