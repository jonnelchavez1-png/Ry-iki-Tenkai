Business receipt tracker

A Telegram bot and web dashboard that work together to make receipt tracking easier.

Status
Working
Type
Telegram bot and web dashboard
Built with
Google Apps Script and the Telegram Bot API, without needing a separate server

What it does

  • Send a receipt photo through Telegram.
  • The system automatically reads the details and saves them to a database.
  • The dashboard is updated with totals and summaries.
  • The bot also answers common questions.

Why I’m building it

I built it to make receipt tracking easier. When I run into a repetitive or messy process, I like to try fixing it with a small tool.
